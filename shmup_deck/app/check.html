Shmup Deck checklist

← back to the deck

Every game the deck supports, and what this MiSTer still needs for each one. ROM zips go in games/mame. Where a line says “or”, either zip will do: the game's own zip from a non-merged or split set, or its parent's zip from a merged set.

A game shows on the deck once its MRA is found; it will only start if the core and ROM zips are there too. Zip names come from each game's MRA and MAME's parent and clone sets. The full list is also on GitHub.
